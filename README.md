# EECE 7205 Assignment #01 - Katherine Tse
## Compile and Run 
This file use a Makefile for compiling. To compile use the  ```make``` command to compile and create an executable. 
The executable is called app and can be run using the ```.\app``` command. 

## Running the Test Suite 
The test suite can be run by using the ```make test``` command. 

## Cleaning 
The build files can be quickly removed by running the ```make clean``` command.
